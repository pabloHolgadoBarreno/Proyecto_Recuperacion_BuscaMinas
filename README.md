# Buscaminas - Proyecto PHP

Este proyecto es una implementación sencilla del clásico juego Buscaminas usando PHP para la lógica y HTML/JavaScript para la interfaz web.

## ¿En qué consiste?

- Genera mapas de Buscaminas con diferentes niveles de dificultad o personalizados.
- Permite guardar y cargar mapas en archivos JSON.
- La lógica del juego está en PHP (`buscaminas.php`).
- La interfaz web está en `index.php` y se comunica con PHP vía AJAX.

## Requisitos

- PHP 7.4 o superior
- Servidor web (Apache, Nginx u otro) con soporte para PHP
- Composer (para manejar dependencias y PHPUnit)
- Navegador web moderno
